# Wisconsin Diagnostic Breast Cancer (WDBC) — ML Classification

Учебный семестровый проект по исследованию и бинарной классификации медицинских данных биопсии (Wisconsin Diagnostic Breast Cancer).

Основная задача — определение характера новообразования молочной железы (доброкачественное `B` или злокачественное `M`) на основе 30 морфометрических характеристик клеточных ядер, полученных при анализе оцифрованных микропрепаратов тонкоигольной аспирационной биопсии (FNA).

---

## 📌 Постановка задачи и медицинская специфика

В задачах медицинской диагностики цена ошибок первого и второго рода неравнозначна:
* **False Positive (FP, ложная тревога):** доброкачественная опухоль классифицирована как злокачественная. Приводит к дополнительным обследованиям и стрессу, но жизнь пациента вне опасности.
* **False Negative (FN, пропуск диагноза):** злокачественная опухоль принята за доброкачественную. Критическая ошибка, задерживающая начало лечения.

Поэтому основной фокус исследования направлен не только на общую точность (Accuracy), но и на **максимизацию полноты (Recall)** по злокачественному классу, а также на подбор оптимального клинического порога принятия решений.

## 📊 Данные

* **Источник:** [UCI Machine Learning Repository — Breast Cancer Wisconsin (Diagnostic)](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic)
* **Объем выборки:** 569 объектов (357 Benign, 212 Malignant)
* **Признаки:** 30 вещественных числовых признаков, вычисленных по характеристикам ядер клеток:
  * Базовые геометрические параметры: `radius`, `texture`, `perimeter`, `area`, `smoothness`, `compactness`, `concavity`, `concave points`, `symmetry`, `fractal dimension`.
  * Каждая характеристика представлена в трех измерениях: среднее (`mean`), стандартная ошибка (`se`) и наихудшее/максимальное значение (`worst`).
* **Пропуски:** отсутствуют.

## 🔬 Методология и этапы работы

1. **Разведочный анализ данных (EDA):**
   * Анализ распределений признаков и проверка баланса классов (~62.7% B против ~37.3% M).
   * Построение корреляционных матриц: обнаружена сильная мультиколлинеарность между размерными метриками (`radius`, `perimeter`, `area` имеют $r > 0.98$), а также между метриками вогнутости (`concavity` и `concave points`).
   * Выделение наиболее информативных признаков (`worst concave points`, `worst perimeter`, `mean concave points`).

2. **Предобработка:**
   * Стратифицированное разбиение выборки (`StratifiedKFold` / `train_test_split` с сохранением пропорции 80/20).
   * Масштабирование признаков с помощью `StandardScaler`, встроенного внутрь `sklearn.pipeline.Pipeline`, чтобы полностью исключить утечку данных (data leakage) из теста в обучение.

3. **Моделирование:**
   * **Baseline:** `DummyClassifier (strategy='most_frequent')` для фиксации базового порога случайного угадывания.
   * **Logistic Regression:** линейный классификатор с регуляризацией L2.
   * **Decision Tree:** дерево решений с контролем переобучения (`max_depth=4`).
   * **Random Forest:** ансамбль из 100 решающих деревьев.

4. **Оптимизация порога (Threshold Tuning):**
   * Смещение порога отсечки логистической регрессии со стандартного $t = 0.50$ до $t = 0.30$.
   * Результат: число пропущенных злокачественных опухолей (FN) сократилось с 3 до 1 на тестовой выборке, подняв Recall до **97.62%** при сохранении Precision на уровне **97.62%**.

## 🚀 Запуск проекта

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/Darhansila/breast-cancer-classification.git
   cd breast-cancer-classification
   ```

2. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux / macOS:
   source .venv/bin/activate
   ```

3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустить ноутбук:
   ```bash
   jupyter lab
   # или
   jupyter notebook
   ```
   Открыть файл `breast_cancer_ml_project_weeks_1_8.ipynb` и запустить все ячейки.
